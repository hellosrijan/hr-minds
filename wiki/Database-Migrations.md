# Database Migrations

Alembic with the async template, in `src/hr_minds/migrations/`. `env.py` reads `settings.DATABASE_URL` (no credentials in `alembic.ini`) and imports the models so `--autogenerate` sees `Base.metadata`.

## Commands

Run from the project root:

| Task | Command |
| :--- | :--- |
| New migration after model changes | `uv run alembic revision --autogenerate -m "describe change"` |
| Apply all pending | `uv run alembic upgrade head` |
| Current revision | `uv run alembic current` |
| History | `uv run alembic history --verbose` |
| Undo last | `uv run alembic downgrade -1` |
| Undo all | `uv run alembic downgrade base` |

Always review an autogenerated script before applying it.

## Adding a model

1. Subclass `Base` (and usually `TimestampMixin`) — see [Architecture](Architecture).
2. Make sure the model is imported in `migrations/env.py`.
3. Autogenerate, review, upgrade.
